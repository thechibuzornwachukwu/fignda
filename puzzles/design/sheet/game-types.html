Relay

Verbal

A chain of words passes a letter to the next: each word's last letter is the next word's first. The shared letter is counted once, so THE + END + DOG reads as THEENDDOG.

The player
Drags across the whole chain. The list shows each link.
The engine
Finds the chains in the letter stream, 3 links or more, and keys each by its span. One link short or long is a near miss.
Fit
Letter stream, spans, word list, hint, reveal and server replay all as they are. No new board

Number series

Quantitative

A row of digits hides runs of 3 or more that step by the same amount. 1, 3, 5, 7 steps by 2. 9, 6, 3, 0 steps by -3. Find each run.

The engine
Enumerates every constant-step run and keys it by its span. One digit short is a near miss. The count comes from the engine, never from the author.
Fit
The digit tiles and server replay already exist for buried sums. The difference rule is new, the board is not. No new board
Also
Show 4 terms and pick the next. Clearer, but it needs a new answer-tile board and a new replay event.

Liar

Verbal

A short paragraph of plain statements. 1 or 2 are false. The player taps the false ones, whole.

The engine
Maps authored statements to spans and checks the pick. It can confirm which statement is marked, not whether it is truly false.
Fairness
Editorial, not computational. Every statement carries a source and is checked by you before it ships. No opinions, no unsourced proper nouns.
Fit
Board, spans and replay fit. The cost is your reading time, not code. Editorial check
